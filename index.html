AI + testing

AI Test Failure Analyzer for Playwright

A failed test leaves a screenshot, video, trace, logs and a stack trace, and someone has to open all of it to decide whether it's a real bug, a flaky test or a broken locator. This tool captures the evidence automatically, classifies it with a deterministic rule set first, and only calls an LLM when asked.

  • Opt-in LLM layer returns a Pydantic-validated root-cause report: category, confidence, severity, suggested fix.
  • The LLM can only be invoked from one function, so CI never makes an API call on its own.
  • Streamlit dashboard over SQLAlchemy 2.0 for failure trends and flaky-test tracking.
